    Configurações

    Letra desta música

    🔎 Buscar no banco de letras

    Escreva o nome do jeito que quiser (pode ser só um pedaço) e escolha o resultado certo.

    ✍️ Colar uma letra

    Formato LRC (ex.: [00:12.50] primeira frase) ou texto simples. Com texto simples, depois use “⏱ Sincronizar letra”.

    📚 Minha biblioteca

    Letras que vocês escolheram, colaram ou sincronizaram no toque, mais os ajustes de sincronia. Exporte para levar a outro aparelho ou passar para os amigos. Ao importar, nada é apagado: as letras são somadas.
